# Этап I. Страница «О нас»

[Индекс плана](../PLAN.md) · [История выполнения](history/README.md) · [Правила шага](../workflows/plan-step.md)

Открытые задачи этапа. Точки входа помогают найти код и не задают полный список правок.
Подшаги и «Готово, когда» определяют объём работы; результаты выполненного — в истории.

Решение пользователя 28.09.2026: страница о проекте, где Freudin сравнивается с сервисами поиска
психологов и с поиском через сарафанное радио и соцсети. Адрес `about` уже зарезервирован,
пользователь занять его не мог.

<a id="step-25"></a>

#### Шаг 25. Текст «О нас»

**Точки входа:** [`docs/PRODUCT.md`](../../docs/PRODUCT.md), [`src/views/home`](../../src/views/home).

- [ ] <a id="step-25-1"></a>**25.1. 🧑‍💻 Разработчик решает:** с чем сравниваем (конкретные сервисы или их типы: каталоги,
      платформы с подбором специалиста) и ключевые тезисы: зачем Freudin и чем он отличается.
      Основа тезисов — `docs/PRODUCT.md`: пять опор и «Чего Freudin не делает».
- [ ] <a id="step-25-2"></a>**25.2. 🤖 ИИ:** черновик на английском: о проекте и таблица сравнения Freudin, сервисов
      поиска, сарафанного радио и соцсетей по критериям вроде «кто выбирает специалиста»,
      «комиссия», «проверка документов», «кто управляет страницей». О чужих сервисах — только
      проверяемые факты со ссылкой на их условия: неточное сравнение с конкурентами — юридический
      риск.
- [ ] <a id="step-25-3"></a>**25.3. 🧑‍💻 Разработчик:** вычитать и утвердить текст.

**Готово, когда:** английский текст и сравнение подготовлены по выбранным тезисам, факты о чужих сервисах имеют источники, разработчик утвердил текст.

# Этап L. AI: подбор психолога и помощь с текстами

[Индекс плана](../PLAN.md) · [История выполнения](history/README.md) · [Правила шага](../workflows/plan-step.md)

Открытые задачи этапа. Точки входа помогают найти код и не задают полный список правок.
Подшаги и «Готово, когда» определяют объём работы; результаты выполненного — в истории.

Опора 3.5 `docs/PRODUCT.md` (29.09.2026): посетитель рассказывает о своём случае, а ассистент
предлагает психологов из каталога с учётом случая, языка, локации и бюджета. Нужны поиск
(шаг 22) и запросы психологов (шаг 29). AI-сервис и бюджет выбираются один раз для шагов 33
и 34.

<a id="step-33"></a>

#### Шаг 33. AI-ассистент

**Точки входа:** [`src/views/home`](../../src/views/home), [`src/app/api`](../../src/app/api).

- [ ] <a id="step-33-1"></a>**33.1. 🤖 ИИ:** предложить схему: AI-сервис и модель; как ассистент выбирает из каталога
      (параметры поиска из рассказа → `GET /api/profiles`); что уходит AI-сервису и что хранится
      (лучше ничего: рассказ — данные о здоровье); предупреждение, что это не медицинская помощь,
      и ответ на кризисные сообщения; лимиты запросов и оценка стоимости.
- [ ] <a id="step-33-2"></a>**33.2. 🧑‍💻 Разработчик решает:** AI-сервис, месячный бюджет и лимит запросов
      на посетителя.
- [ ] <a id="step-33-3"></a>**33.3. 🤖 ИИ:** API ассистента (ключ AI-сервиса — серверная переменная), интерфейс
      на главной, rate limiting (шаг 18.3), `/privacy` и `/terms`: новый получатель данных
      и данные о здоровье.
- [ ] <a id="step-33-4"></a>**33.4. 🧑‍💻 Разработчик:** аккаунт AI-сервиса и ключ в Vercel, проверка на проде на разных
      сценариях.

**Готово, когда:** посетитель без регистрации описывает свой случай и получает подходящих
психологов из каталога со ссылками на их страницы.

<a id="step-34"></a>

#### Шаг 34. AI-помощь с описанием «О себе»

**Точки входа:** [`src/widgets/profile-form`](../../src/widgets/profile-form), [`src/app/api`](../../src/app/api).

Запрос пользователя 29.09.2026: по данным психолога AI предлагает текст блока Bio, психолог
правит его и сохраняет сам.
- [ ] <a id="step-34-1"></a>**34.1. 🤖 ИИ:** предложить схему: какие данные профиля идут в запрос (подходы, с кем
      работает, формат, стаж, образование, языки; без закрытых данных — по решению 🧑‍💻), как это
      выглядит в настройках (кнопка у поля Bio, черновик, который можно поправить или отклонить),
      язык текста, лимит 500 символов, лимиты запросов.
- [ ] <a id="step-34-2"></a>**34.2. 🧑‍💻 Разработчик решает:** схему и AI-сервис (вместе с 33.2).
- [ ] <a id="step-34-3"></a>**34.3. 🤖 ИИ:** API и интерфейс, rate limiting (шаг 18.3), `/privacy`: данные профиля
      уходят AI-сервису.
- [ ] <a id="step-34-4"></a>**34.4. 🧑‍💻 Разработчик:** проверка на проде.

**Готово, когда:** психолог в настройках получает предложенный текст Bio по своим данным
и сохраняет его после правки.

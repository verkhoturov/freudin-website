Выполненные подшаги и результаты проверок — в [истории](history/stage-e.md#step-16).

- [ ] **🤖 ИИ:** вошедший пользователь видит на главной «My page» или «Create page», как в меню
      шапки, а не «Sign in».
- [ ] **🤖 ИИ:** тексты объясняют специализацию Freudin на психологах и ценность профессиональной
      визитки. До готовности каталога не обещать доступный поиск; после шага 22 разделить

**Готово, когда:** вошедший пользователь видит My page или Create page; тексты главной объясняют визитку психолога и не обещают ещё недоступный поиск.

<a id="step-22"></a>

#### Шаг 22. Поиск психологов на главной

**Точки входа:** [`src/views/home`](../../src/views/home), [`src/entities/profile`](../../src/entities/profile), [`src/app/api`](../../src/app/api).

**Связи:** Сначала решение [22.1](stage-e.md#step-22-1); исходные данные — шаги 20 и 29 в истории; лимиты — [18.3](stage-f.md#step-18-3).

Решение пользователя 28.09.2026: на главной поиск по подходу, формату работы и локации. Нужны данные
из шага 20.
- [ ] <a id="step-22-1"></a>**22.1. 🧑‍💻 Разработчик решает:**
      - кто попадает в выдачу: все профили или только с заполненными данными психолога (и с
        проверенными документами, если будет проверка);
      - фильтры: подход, формат работы, страна и город, язык (решено в 20.2); нужны ли фильтры
        «С кем работает» и по цене;
      - порядок выдачи и сколько карточек загружать за раз.
- [ ] <a id="step-22-2"></a>**22.2. 🤖 ИИ:** `GET /api/profiles?approach=&format=&country=&city=&language=&cursor=`:
      публичный клиент, query через zod, пагинация, только публичные колонки, индексы из 20.3.
      Фильтры по возрасту, полу и запросам (шаг 29) читают `profile_private`, которую гость не
      видит: нужна серверная функция или запрос с правами сервиса, не отдающий сами значения.
      Лимит запросов — вместе с 18.3.
- [ ] <a id="step-22-3"></a>**22.3. 🤖 ИИ:** поиск на главной: фильтры хранятся в адресе (`useSearchParams`, компонент в
      `<Suspense>`), поэтому поиском можно поделиться ссылкой; карточки результатов (фото, имя,
      подход, формат, город) со ссылкой на страницу; скелетоны, пустая выдача, «Load more». SEO:
      один `<h1>`; выдача рендерится на клиенте, поисковики её не увидят (этап G).
- [ ] <a id="step-22-4"></a>**22.4. 🤖 ИИ:** README: роут; каталог `docs/code-map.md`: слайсы и запросы.
      Новые правила, если понадобятся, — в соответствующем workflow.
- [ ] <a id="step-22-5"></a>**22.5. 🧑‍💻 Разработчик:** проверка на проде: фильтры, ссылка с фильтрами, пустая выдача,
      телефон.

**Готово, когда:** на главной можно найти психологов по подходу, формату работы и локации, а ссылка
с фильтрами открывает ту же выдачу.
